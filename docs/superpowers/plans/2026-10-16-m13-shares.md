# M13 Shares Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Invoke `ponytail:ponytail` before writing code.

**Goal:** Replace the exclusive sealed-bid auction with fractional share buying, remove the bench, and make games 2v2 with share-weighted scores, for leagues of up to 12 teams.

**Architecture:** Same split as today. `src/core` (pure TS) settles shares and scores 2v2 games from league-readable rows in the browser. One migration, `0023_shares.sql`, rewrites the auction and pick RPCs, drops the bench, and changes keys. The UI changes the buying card, the pick card and scoreboard (with an explicit score breakdown), the Rules page and the admin labels.

**Tech Stack:** Vite + React 19 + TypeScript, Supabase Postgres (security-definer RPCs), vitest + PGlite DB tests.

**Spec:** `docs/superpowers/specs/2026-10-16-shares-design.md`. Read it first. Decisions 1–11 and calls C1–C11 are binding.

## Global Constraints

- Before every commit: `npm run typecheck`, `npm run lint`, and the task's tests. Before the final review, run `npm test` (ALL files together, as CI does) plus `npm run build`.

- Commit message: blank line, then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` as the last line.

## Review Focus

1. **A team that bought into 0 or 1 players.** It plays with what it has: 0 is a forfeit; 1 starts 1 player against 2. No crash, no pick email every game (C9). Tests: core T3 Step 1 "short roster", DB T4 notify test.
2. **Both opponents start the same player.** Each side scores its own share; the card shows the name on both sides. Tests: T3 Step 1.
3. **A third pick tapped.** It is refused in SQL (`TOO_MANY_PICKS`) and in the UI (asks you to clear one first). Tests: T4, T5.
4. **A balance cut after buying (C5)** and **a 7th player bought.** The first drops unaffordable buys largest-first, and the pools exclude them. The second is refused at buy time (`TOO_MANY_PLAYERS`). Tests: T2, T4.
5. **12-team league pairing and Check pairings.** `checkPairing` must accept orders up to 12 (it rejects >8 today). Tournament rematches are avoided before season ones. Tests: T1, T5.
