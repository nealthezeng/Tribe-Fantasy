## Approved design (user, 2026-10-22)

- **Six rules.** (1) The row is the button: anything that opens something is a whole-row target with a drawn chevron; no small button beside a row. (2) One gold button at a time: gold = the one action due now; done steps become words. (3) Say it the way people count: shares as %, "Game 2 vs UNC", "2nd of 9", multipliers in words only when they change something. (4) One line per game, grouped by tournament. (5) Status is a word and a dot, not a pill stack; pills only for what is wrong or needs you. (6) Show the league: a short table on League.
- **League tab = layout A:** matchup, scoreboard, starters, the pick card, a short league table (replaces the Place/Record/Points tiles, "Full table" opens Leaderboards), games grouped by tournament, League settings. Leaderboards stays a tab.
- **Stuck game = warn and explain** (no scoring change). **Admin = full rework** (rows open their actions, settings as labelled fields, four groups). **Finish game = a quiet button at the end of the tally board.** **Join a league shows members' first names** (privacy loosened by the user's choice). **No game start times**: copy states the lock rule.

## Rulings made while planning

1. **Status words** (one set everywhere, `lib/words.ts`): `upcoming` → "Not started"; `live` → "Live" with the red `.live` dot; `pending` → "Finished · not verified"; `final` → "Final"; `void` → "Doesn't count". A game the core demoted because an earlier game isn't verified (`heldBy` set) reads "Final" plus the note "counts once {Stage} game {n} is verified". Live numbers keep the word "unofficial" next to them.
2. **Game name:** `gameName(number, opponent)` = "Game 3" or "Game 3 vs UNC". It replaces `gameLabel` everywhere (`gameLabel` is deleted). `gameTitles` returns "Game 1 vs Duke · CCCs". "vs" always sits between two scores (never "to").
3. **Stat words in sentences:** "1 goal, 2 assists, 1 block, 1 callahan, 2 turnovers" (`statWords`). "D" stays on tally buttons and table heads, with a legend under every stat table: "G goals · A assists · D blocks · C callahans · T turnovers". No stats: "no stats yet" (game not final) or "didn't play" (final).
4. **Rest words** (`restWords(rest, number, settings)`): rest 1 → "rested"; `tiredness_multipliers[i]` → "played game {number − 1 − i}: {fraction} points" where 0.5 → "half", 0.75 → "¾", 0.25 → "¼", else "{n}%". Decay below 1 adds "earlier tournaments: {pct}".
5. **Pick rows replace Pick buttons and the × chip:** the whole row is a `button.pick-row` with `aria-pressed`; text "Ari Banks" then small "Your 20% · played game 1: ¾ points"; a drawn ring fills green when picked. Out players: `pill bad` "Out", disabled unless already picked (tapping a picked Out player clears him).
6. **Unpaired next game is pickable** (the DB already allows it): hint "You'll see who you play once game {n − 1} ends. Picks lock when a keeper starts game {n}." Paired: "You play {Team}." + "Picks lock when a keeper starts game {n}." Bye: "Bye in game {n}: no opponent, so your standings points don't change." Paired in the game but not in any matchup (joined after pairing): "You joined after game {n} was paired, so you start the game after it." No roster: "You have no players this tournament, so you can't score." (replaces "No players: you forfeit.").
7. **Notices become hint text:** every `Notice` line renders as `p.hint`, never a `.notice` box (fixes nested boxes in opened games and the pick card jumping).
8. **Short table rows** (`shortRows`): the first 3 rows, plus your row and the rows just above and below it; every skipped run becomes one gap row "{n} more teams". Before any counted game the card shows "Standings start after the first game." with no rows.
9. **Games list:** the current tournament (the one `next` is in, else the newest with a started game) lists every game, one line each: number, both teams with scores (yours first), the status word or "Pick {k}" (gold text) for the next game. Earlier tournaments you played in collapse to one `details` row each ("Feasterns · 4 games · 2–1"); tournaments you weren't in are not listed. A game line opens (inline `details`) to your matchup first (both sides, "5 × 20% = 1" lines) and then "Other matchups", one line each, each opening to its two sides.
10. **Starter lines:** "{Name} · {statWords} · {base} × {exact %}" and the points, e.g. "Finn Garza · 1 goal, 1 assist · 6 × 12.5%  0.75". Exact % = factor × 100 to 3 significant figures (`pctExact`).
11. **Keeper line on League:** a keeper while the playing stage has a live game sees a card "{Stage} · Game {n} vs {Opp}" with the live dot and "Tally game {n}" (`/tally?game=<session>`): a gold `Link.button` when they have no team this season, a `.more` link otherwise. A keeper with no team sees "You don't have a team this season." and a `.more` "Join a league" instead of the "Get started" card.
12. **Late joiner:** player side, while buying is open and the team has no `allowance` ledger row for that stage: `p.notice` "You joined after {Stage} credits went out. Ask an admin to add yours." Admin side (Round 2): the open stage's card says "{n} team(s) have no {Stage} credits" with the gold "Give them their credits" (re-runs Grant allowance, which only credits teams without one).
13. **Credits arrived:** if the newest ledger row is an `adjustment` with amount > 0 made in the last 7 days, the buy card shows `p.success` "An admin added {n} credits.".
14. **Buy feedback:** after a successful save, that row shows `small.success` "Saved: {n} credits on {Name}." until the next save anywhere.
15. **Tally board** "Picked this game" group = every athlete any team starts in this game per the core (`startersOf`), then "Everyone else", both A→Z; search filters both. If the starters fail to load the board shows one A→Z list, as today.
16. **B3 (Back to the board):** "← Games" pushes `/tally` instead of replacing the board's history entry, so Back from any page opened afterwards walks back to the board.
17. **Admin tabs:** four group chips (Tournaments, Teams, People, More) and text sub-tabs; the address is `#/admin?tab=<id>` with ids `stages`, `leagues`, `wallets`, `users`, `athletes`, `settings`, `history`, `backup`, `season`. The page remembers each tab's scroll for this visit. The season being managed defaults to the newest without mounting the Seasons panel; switching, renaming, deleting and creating seasons live in More › Season.
18. **Stuck game warning** (admin): any game whose tournament's last day has passed and which started but isn't verified. Text "{Stage} game {n} is still live." or "{Stage} game {n} isn't verified." then "Later results won't count until it's verified." Link "Open {Stage} game {n}" → `/stats/<session>` (Verify lives there; verifying makes it final even unfinished).
19. **Close buying now** (admin): new RPC `close_share_buying(p_stage)`; confirm "Close buying for {Stage} now? Teams can't buy or change shares after this, and it can't be reopened."
20. **Icons:** redraw `public/icon-512.png` (and 192, apple 180 for consistency) with the crest at 65% (was 66%), so the banner tail sits inside the maskable circle.
